# Протокол: Бункер 7

Мини-игра по мотивам настольной игры «Бункер» для SMP-сервера на Minecraft 1.21.1 (NeoForge).

Организация «Сектор» зафиксировала катастрофу. Мест в бункере меньше, чем людей. Каждый получает
досье из восьми карт и по очереди раскрывает их, а группа решает, кого оставить внутри.
Сектор наблюдает, кого вы выберете.

Игра идёт сама после одной команды админа: бункер, таймеры, ходы, голосования и финал ведёт сервер.
Обсуждение идёт в голосовом чате.

## Возможности

- **Своё измерение и бункер.** Пустое измерение `bunker7` и генерируемое советское убежище:
  - Зал совета: 16 мест по кругу и табло, которое само показывает вскрытые карты всех игроков;
  - комната голосования;
  - «Поверхность» в тумане Взвеси, куда уходят изгнанные; она стоит дальше 48 блоков от Зала, за пределом голосового чата;
  - отсек Реактора для финального испытания.
- **Вещи игроков в сохранности.** Инвентарь, позиция и слоты Curios сохраняются до телепорта и всегда
  возвращаются: в конце игры, по `/bunker7 stop`, при выходе игрока и после рестарта сервера.
- **Безопасность.** Внутри урон отключён полностью, игроки в режиме adventure, стены неразрушимы.
- **Карты.** У каждого восемь карт: профессия, здоровье, биология, хобби, фобия, багаж, факт и особое действие.
  В одной игре карты не повторяются. Стартовый набор на русском: 220 карт, 8 катастроф и 6 бункеров.
- **Досье** открывается клавишей **B** или предметом «Досье». Вкладки:
  - мои карты;
  - игроки;
  - бункер;
  - особое действие.
- **Раунды.** Игроки ходят по очереди. В первом раунде все вскрывают профессию, дальше любую карту на выбор.
  За ходом идёт обсуждение, затем голосование. Чей ход и сколько осталось, показывает боссбар.
- **Голосование** идёт в отдельном экране «Бюллетень». Голос тайный, итоги объявляются открыто.
  При ничьей претенденты оправдываются, затем переголосование. При повторной ничьей никто не уходит.
  Если ничья повторилась в последнем раунде, изгнанного выбирает жребий Сектора.
- **12 одноразовых особых действий:** обмен картами, вскрытие чужой карты, двойной голос,
  неприкосновенность, протекция, перераздача здоровья и багажа и другие.
- **Финал.** Титр «Двери бункера закрыты» и итоговая сводка. Если стоит Create, выжившие проходят
  испытание: за отведённое время нужно раскрутить Реактор механизмами Create.
- **Вышедший игрок.** Его ход пропускается, а когда он вернётся, ход ему вернут.
  Если он не вернётся до конца раунда, он считается изгнанным.
- **Режим отладки.** Игра в одиночку с «фантомами»: стойки для брони, которые сами вскрывают карты и голосуют.

## Требования

| | Версия | |
|---|---|---|
| Minecraft | 1.21.1 | |
| NeoForge | 21.1.x | обязательно |
| Create | 6.0.10 | необязательно: без него нет финального испытания |

Мод ставится и на сервер, и на клиент.

## Быстрый старт

1. Положите jar мода в `mods/` на сервере и у игроков.
2. Постройте бункер: `/bunker7 build` (повторная постройка: `/bunker7 build force`).
3. Запустите игру: `/bunker7 start`, или `/bunker7 start players <игроки>`, или `/bunker7 start radius <блоки>`.

Попробовать одному: `/bunker7 debug on`, затем `/bunker7 start players @s`.
По умолчанию к вам добавятся три фантома.

## Команды

**Админ** (`/bunker7`, уровень прав 2):

| Команда | Что делает |
|---|---|
| `build [force]` | построить или перестроить бункер |
| `tp` | перейти в бункер |
| `start [players <игроки> \| radius <блоки>]` | начать игру |
| `stop` | остановить игру и вернуть всех домой |
| `next` | закончить текущий ход или фазу |
| `pause` / `resume` | пауза |
| `status` | состояние игры и все карты всех игроков |
| `card <игрок> <тип> <id>` | выдать карту (только в отладке) |
| `debug on\|off` | режим отладки: любое число игроков, фантомы |
| `debug phantoms <0-15>` | сколько фантомов добавить в отладочную игру |

**Игроки** (`/b7`): `dossier`, `info`, `reveal <тип>`, `end`. То же самое есть в досье.

## Как идёт игра

1. **Начало.** Объявляются катастрофа, бункер (площадь, запасы, срок, что внутри) и число мест.
   По умолчанию мест половина от числа игроков, с округлением вниз.
2. **Раунд:**
   - **Вскрытие.** Игроки ходят по очереди, ход длится 90 секунд. Если игрок не выбрал карту вовремя, вскрывается случайная.
   - **Обсуждение.** 5 минут.
   - **Голосование.** 1 минута. Игроки переходят в комнату голосования, и у каждого открывается бюллетень.
3. **Изгнание.** Изгнанный вскрывает все карты и уходит на «Поверхность» с подзорной трубой.
4. **Конец игры.** Когда в бункере остаётся столько людей, сколько мест, двери закрываются: все карты
   вскрываются и в чат выводится сводка. Затем идёт испытание с Реактором, если оно включено.
   Через 20 секунд все возвращаются домой.

Сколько игроков изгоняют в каждом раунде, задаёт таблица в конфиге. Её можно настроить.

## Настройки

Файл `mafia_sector-server.toml` (серверный конфиг):

| Ключ | По умолчанию | Смысл |
|---|---|---|
| `game.minPlayers` | 4 | минимум игроков (без отладки) |
| `game.seatsPercent` | 50 | места в бункере, % от игроков |
| `game.rounds` | 5 | число раундов, если игроков нет в таблице |
| `game.roundTable` | `"10=0,1,1,1,2"`, ... | изгнания по раундам для каждого числа игроков |
| `timers.introSeconds` | 15 | вступление |
| `timers.turnSeconds` | 90 | ход одного игрока |
| `timers.discussionSeconds` | 300 | обсуждение |
| `timers.votingSeconds` | 60 | голосование |
| `timers.justifySeconds` | 30 | оправдания при ничьей |
| `timers.finalSeconds` | 15 | сводка перед испытанием |
| `timers.endingSeconds` | 20 | время до возвращения домой |
| `timers.debugTimeScale` | 1.0 | множитель таймеров в отладке |
| `finalTrial.enabled` | true | финальное испытание (нужен Create) |
| `finalTrial.minutes` | 5 | время на испытание |
| `finalTrial.reactorSpeed` | 32 | нужная скорость, об/мин |
| `finalTrial.reactorPowerPerSurvivor` | 256 | нужная мощность на выжившего, SU |
| `finalTrial.reactorHoldSeconds` | 10 | сколько секунд нужно удержать |

## Свои карты

Карты, катастрофы и бункеры лежат в датапаке, пространство имён `bunker7`.
Их можно заменить своим датапаком без пересборки мода и применить через `/reload`.
Файл из датапака заменяет файл мода целиком.

```
data/bunker7/cards/<тип>.json   profession, health, biology, hobby, phobia, baggage, fact, action
data/bunker7/catastrophes.json
data/bunker7/bunkers.json
```

Карта:
```json
{"cards": [
  {"id": "surgeon", "text": "Хирург", "detail": "Стаж 15 лет. Руки не дрожат, когда трезвый."}
]}
```
`text` выводится на табло, поэтому он должен быть коротким. `detail` — пояснение, его видно в досье.
Карте особого действия нужно ещё поле `"action"` со значением из списка: `barter`, `blind_swap`, `expose`,
`double_vote`, `immunity`, `epidemic`, `protection`, `second_chance`, `customs`, `gag`, `confession`, `doctor`.

Катастрофа: `{"id", "title", "description"}`.
Бункер: `{"id", "title", "area", "supplies", "duration", "features": [...]}`.

Карт каждого типа должно быть не меньше, чем игроков. Ошибки в данных видно в `/bunker7 status`.

## Сборка и разработка

```
./gradlew build              # jar в build/libs
./gradlew runClient          # клиент
./gradlew runServer          # сервер
./gradlew runGameTestServer  # тесты: постройка, сохранение вещей, целые партии, особые действия
```

Create и Curios для dev-запусков копируются из папки `mods/`. Её нет в репозитории:
положите туда `create-1.21.1-6.0.10.jar` и `curios-neoforge-9.5.1+1.21.1.jar`.
